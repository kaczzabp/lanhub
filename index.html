ONE PAGE FOR THE WHOLE LAN PARTY.

Lanhub is a self-hosted hub you run on one machine. Everyone on the network opens the same page: live chat, polls, a shared checklist, a food menu with ordering, download links, and announcements. No internet, no accounts, no cloud.

// SCREENSHOTS

Three views of the running hub: login, console, and host controls.

[01] GUEST LOGIN

Guests join with a short code the host hands out. No account, no email, nothing to install. Hosts sign in on a separate tab with the server password.

[02] LIVE CONSOLE

The terminal shows everything the host needs: the LAN address to share, the generated admin password, and a live counter of who is online.

[03] HOST ADMIN PANEL

The host panel stays invisible to guests. Generate codes, pin announcements, build polls and the food menu, share links or 2 GB uploads, and push a giant clock to every screen.

// FEATURES

Two sides of the same page: what guests get and what the host controls.

◉

FOR GUESTS

  • Guest codes. Log in with a short code, no account needed.
  • Live chat. Real-time group chat with history.
  • Polls. One vote per person, results update live.
  • Checklist. A shared list everyone ticks off, plus a matrix view of who ticked what.
  • Links and downloads. Installers, drivers, and pinned URLs in one place.
  • Food menu and ordering. Browse the menu and order; the host sees every order with totals.
  • Announcements. A pinned banner across the top, dismissible per person.
  • Online now. The sidebar shows who is connected.
#

FOR THE HOST

  • Admin panel. Separate password, never visible to guests.
  • Guest codes. Generate codes with seat and game handle, revoke them, see who is online.
  • Poll management. Create, close, reopen, and delete polls.
  • Menu builder. Sections and prices, open and closed ordering, per-person totals.
  • Clock mode. Turn every screen into a giant clock with the announcement. Made for the projector.
  • Section toggles. Hide any section from everyone with one click.
  • Links and uploads. Pin URLs or upload files up to 2 GB each.
  • Hardened by default. Rate-limited logins and sessions that expire after 24 hours.

// QUICK START

Requirements: Node.js 18 or newer. On first run the admin password is generated and printed to the console.

>

RUN IT

git clone https://github.com/kaczzabp/lanhub.git
cd lanhub
npm install
node server.js

First party checklist: log in under HOST LOGIN with the printed password, open the admin panel, generate a code per person, and hand them out. Guests enter their code and they are in.

// ACCESSING THE HUB
